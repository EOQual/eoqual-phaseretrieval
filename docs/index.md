# eoqual-phaseretrieval

Restitution du front d'onde à partir de la PSF (PSF → WFE → coefficients de Zernike) : Gerchberg-Saxton, ajustement direct des coefficients de Zernike, diversité de phase (focus + défocus connu, pondération Poisson, pertes robustes) ; prise en compte d'une WFE haut ordre mesurée indépendamment, simulateur de PSF et de paires de diversité de phase, interface en ligne de commande.
